# PR note: v0.9 package-version alignment

## Why

The repository had reached the v0.9 recovery and evaluation milestones, but the package
metadata and `contextopt --version` still reported `0.8.0a1`. That makes copied artifacts,
bug reports, and interview demonstrations ambiguous about which protocol surface is running.

## What changed

- Align the packaging metadata and runtime `__version__` at `0.9.0a1`.
- Add a regression test proving the imported version matches installed distribution metadata.
- Record the change in both English and Chinese PR notes.

## Validation

```text
python -m unittest tests.test_package_metadata -v
python -m contextopt --version
python scripts/ci_checks.py
```

## Claim boundary

This is release identity bookkeeping; it does not claim a new model capability, provider
compatibility, or statistically powered real-model benchmark. The v0.9 label refers to the
implemented local recovery/evaluation milestone described in the repository docs.
