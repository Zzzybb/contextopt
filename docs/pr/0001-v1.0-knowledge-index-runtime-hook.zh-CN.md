# PR 说明：v1.0 knowledge-index 运行时入口

workspace 索引现在可以直接从单 Agent 入口使用：

- `run --auto-index-knowledge` 会在第一次模型请求前刷新有界源码投影；
- 该 flag 必须显式提供 semantic-memory store 和 scope，避免索引写入后却无法被上下文策略检索；
- 可选 JSON/Markdown report 路径暴露索引记账，不会污染 run 结果流；
- `resume` 不会在 pending request 前静默修改 durable store，保持显式恢复配置边界。

新的 CLI 路径由本地 round-trip 测试覆盖。它仍使用 lexical、source-aware memory，不声称
embedding 质量，也不声称模型使用了每条检索结果。

```text
python -m unittest tests.test_knowledge -v
python scripts/ci_checks.py
```
