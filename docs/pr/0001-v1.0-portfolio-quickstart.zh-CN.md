# PR 说明：v1.0 作品集快速入口

## 改动内容

- 在中英文 README 中增加安装包并运行 provider-free 多模型矩阵 demo 的短入口。
- 直接指向生成的自包含 HTML dashboard 和获授权后的真实 provider workflow。

## 为什么做

仓库内部实现很深，但审阅者应该能在一分钟内看到可运行的 ACM/数学 Agent 评测产物。这个
quickstart 让学习/作品集路径清晰，同时保持确定性控制副本与真实模型证据的边界。

## 验证

~~~text
python scripts/run_model_matrix_demo.py
python scripts/ci_checks.py
~~~

## 结论边界

quickstart 只运行无需 provider 的 `ScriptedModel` 控制副本。生成的 HTML 证明本地 evaluator
和记账管线可用，不证明代码能力或模型泛化。
