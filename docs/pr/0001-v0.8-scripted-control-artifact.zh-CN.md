# v0.8 PR 补充：脚本化三次重复控制实验产物

## 本次改动

- 为两个内置 fixture（`two-sum` 和 `extended-gcd`）提交确定性的三次重复
  `agent-eval` 实验产物。
- 覆盖 `single_pass`、`best_of_n`、`orchestrated` 三种策略，并记录 visible test、独立
  hidden grader、配对差值、Wilson 区间、token/model-call 预算、checkpoint 和复现 manifest。
- 新增实验目录说明，并从中英文项目入口链接到该产物。

## 验证

在仓库根目录执行下面的命令即可重新生成同一组产物：

```text
python -m contextopt agent-eval --fixtures all --repetitions 3 \
  --output experiments/v0.8-scripted-3-reps/report.json \
  --markdown experiments/v0.8-scripted-3-reps/report.md \
  --html experiments/v0.8-scripted-3-reps/report.html \
  --checkpoint experiments/v0.8-scripted-3-reps/checkpoint.json \
  --manifest experiments/v0.8-scripted-3-reps/manifest.json
```

当前提交的运行包含 18 次评测：两个 fixture × 三种策略 × 三次重复。生成的报告包含
visible/hidden 通过率、配对比较、置信区间、预算以及 checkpoint/manifest 元数据。

## 边界

这是用于验证协议和记账的控制基线，不是真实模型代码能力证据。响应来自确定性的
`ScriptedModel`，没有测量 provider 稳定性、泛化、延迟或生产安全性。要做模型能力结论，
必须换成明确版本的真实 provider，配置 API key 后重新运行同一矩阵。
