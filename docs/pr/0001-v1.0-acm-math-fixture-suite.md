# PR #1 — v1.0 ACM/math fixture suite expansion

## What changed

- Expanded the executable coding-agent matrix from two to four complete root snapshots:
  `two-sum`, `merge-intervals`, `extended-gcd`, and `modular-inverse`.
- Added visible and independent hidden graders for interval ordering/overlap, input
  immutability, modular inverses with negative values, and non-coprime moduli.
- Kept the same `single_pass`, `best_of_n`, and planner/solver/reviewer `orchestrated` controls,
  candidate budgets, hidden-grader gate, checkpoint schema, and paired statistics. The CLI's
  `--fixtures all` now resolves from the fixture registry instead of a hard-coded two-item list.
- Updated the English and Chinese README/runtime/evaluation descriptions so the real-provider
  workflow has a broader ACM/math task surface before any authorized model run.

## Validation

```text
ruff check src/contextopt/evaluation/agent_search.py src/contextopt/cli.py tests/test_agent_search_eval.py
python -m unittest tests.test_agent_search_eval.AgentEvaluationFixtureTests
python -m unittest discover -s tests -v
```

The scripted all-fixture matrix produces 12 cells for one repetition; the two stronger
strategies pass visible and independent hidden graders on all four fixtures, while the weak
single-pass control remains a recorded failure.

## Claim boundary

The added tasks improve coverage and adversarial diversity, but scripted responses remain a
protocol/control baseline. They do not establish real-model coding ability, generalization,
provider reliability, or statistical significance. Real-model evidence still requires a fixed
provider/model/prompt/budget matrix with at least three authorized repetitions.
