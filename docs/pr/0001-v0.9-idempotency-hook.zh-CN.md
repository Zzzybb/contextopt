# v0.9 PR 补充：durable model request 幂等钩子

## 本次改动

- 用 `run_id`、turn 和完整 request SHA-256 生成确定性的 key。
- `model.requested` 事件持久化该 key，便于审计和恢复诊断。
- `OpenAICompatibleModel` 默认在 `Idempotency-Key` header 中发送同一个 key；编程式调用
  可以设置 `idempotency_header=None` 明确关闭 header。
- adapter 配置 fingerprint 包含 header 选择，恢复时不能悄悄改变 provider 边界。

## 验证

- `python -m unittest tests.test_runtime_model tests.test_runtime_resume -v`
- `python scripts/ci_checks.py`
- `python -m unittest discover -s tests -q`

测试覆盖 transport retry 时 key 稳定、不同逻辑 turn 使用不同 key、header 传递以及 durable
事件记录。

## 边界

这个 key 是互操作钩子，不是本地 exactly-once 承诺。provider 可能忽略 header，重试仍会在
append-only ledger 中可见。speculative solver lane 仍保留文档中的 response-to-checkpoint
崩溃窗口；provider-aware cancellation 和 winner selection 仍是后续工作。
