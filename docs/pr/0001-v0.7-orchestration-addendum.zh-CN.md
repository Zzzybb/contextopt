# PR 说明：v0.7 planner / solver / reviewer 编排补充

这份中文说明回顾 PR #1 之后加入的 v0.7 角色编排层。

## 改动内容

- 增加严格的 planner、solver、reviewer JSON 协议；solver 复用完整工作区快照提议解析器；
- 增加顺序执行的 `OrchestrationRunner`，串起 planner、solver、临时工作区可见测试和
  reviewer 阶段；
- 增加共享模型/token/候选/测试预算、角色模型指纹、跨轮反馈、缓存观察、原子 checkpoint、
  角色调用哈希和 Markdown 输出；
- 增加 oracle gate：只有 reviewer accept 且存在可见测试通过的候选才会 accepted，
  reviewer 自报 confidence 不能覆盖可执行测试结果；
- 增加 `orchestrate` CLI、确定性角色协议测试，以及中英文 README/PR 文档。

## 验证命令

~~~text
python -m unittest tests.test_orchestrator -v
python -m ruff check src tests
python -m ruff format --check src tests
python -m mypy src/contextopt
~~~

这些检查证明 ScriptedModel 下的协议、预算、持久化和安全行为；不能证明真实模型编码
质量、hidden-test 成功率或多 Agent 优势。并行隔离工作区、自适应调度和受控真实模型
benchmark 属于后续里程碑。
