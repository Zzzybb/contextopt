# PR 说明：v1.0 精确配对结果证据

## 为什么做

策略矩阵已经把每个候选和相同的 fixture、repetition 配对，但报告以前只有胜/负/平和
描述性的结果差值。审阅者可以看出方向，却缺少一个能快速说明“真正不一致的配对有多少”
的二元结果诊断。

## 改动内容

- 为 visible 配对结果增加精确双侧 McNemar p 值；对于两边都实际执行独立 hidden grader
  的配对 cell，也对可用的 hidden 配对结果增加该值；
- JSON 持久化这些字段，并在 Markdown 和自包含 HTML 报告中展示；
- 保留原始胜/负/平和差值，p 值只是从 fixture/repetition ledger 可审计地推导出的补充，
  不是替代指标；
- 导出并用单元测试覆盖标准库实现，包括“没有 discordant pair”和“全部获胜”两种边界。

## 验证

```text
python scripts/ci_checks.py
python -m unittest tests.test_agent_search_eval
```

实现基于 McNemar 零假设下的 discordant-pair 条件二项分布，计算双侧尾概率。如果比较中
没有可用的 hidden 配对结果，hidden 字段会显示为 `n/a`，不会伪造统计值。

## 结论边界

这只是探索性的配对二元结果诊断，不是有统计功效的 benchmark、多重比较校正，也不能证明
某个 Agent 策略提升了通用 ACM/数学代码能力。当前 scripted 控制产物每个 fixture 只有三次
重复，并且故意不调用 provider。真实 provider 结论仍需要固定 model/prompt/tool 矩阵、更多
重复、保留失败轨迹以及预先写明的分析方案。
