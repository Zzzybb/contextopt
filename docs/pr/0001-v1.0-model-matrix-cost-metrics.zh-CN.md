# v1.0 多模型矩阵成本指标

## 改了什么

配对多模型 Markdown 和 HTML 渲染器现在会在 visible/hidden 结果旁直接展示每个模型、每种策略的
平均模型调用数、测试调用数、provider token 用量和本地耗时。机器可读 JSON 原本已经保存这些字段；
这次把质量/成本权衡放到作品集 dashboard 里，不需要先打开原始 ledger。

## 为什么改

Agent 策略不能只展示更高的成功率而隐藏额外调用、测试、token 或墙钟时间。比较产物要把结果和资源
指标放在一起，面试官才能看到真实权衡，并用同一份 report 复现。

## 如何验证

- `python -m unittest tests.test_model_matrix -v`
- `python scripts/ci_checks.py`
- `python scripts/run_model_matrix_demo.py --output-dir build/model-matrix-demo`

## Claim boundary

这些是观测到的记账指标：有 provider 时 token 来自响应，没有 provider 时来自确定性控制模型；耗时是本地
墙钟诊断。它们不代表 provider 价格、延迟 SLA、模型能力、因果关系或生产安全。
