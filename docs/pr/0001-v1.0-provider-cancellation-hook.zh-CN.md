# PR 说明：v1.0 provider cancellation hook

## 为什么做

speculative solver 已经会记录 winner，并请求未完成的 lane 停止，但此前通用的
OpenAI-compatible adapter 没有办法通知 provider-specific 的远端 abort API。因此
`acknowledged` 只能表示本地 HTTP response 已关闭。

## 改动内容

- 为 `OpenAICompatibleModel` 增加可选 `cancellation_url`，并为 `run`、`resume`、
  `search-session`、`propose-case`、`orchestrate`、`agent-eval` 增加 `--cancellation-url`；
- 本地设置 cancellation event、关闭活动 response 后，向该 endpoint POST
  `{"request_idempotency_key": "...", "model": "..."}`；
- 复用配置的 authorization 和 idempotency header：2xx 映射为 `acknowledged`，404/405 映射为
  `unsupported`，其他 HTTP/网络错误映射为 `failed:*`；
- 将 endpoint 写入不含 secret 的 adapter configuration，使 resume 能拒绝变化后的取消协议；
  manifest 会去掉 query string 和 fragment；
- 增加 provider-free 的成功/unsupported endpoint 测试，并保留本地传输取消回归测试。

## 验证命令

```text
D:\vnpy\python.exe -m unittest tests.test_runtime_model -v
python scripts/ci_checks.py
```

## 结论边界

该 endpoint 是显式的 provider 集成协议，不是 Chat Completions 标准。2xx 只表示配置的
endpoint 接受了 abort 请求，不能独立证明服务端生成已经停止，也不能证明远端计费已经避免。
测试不会访问真实 provider。
