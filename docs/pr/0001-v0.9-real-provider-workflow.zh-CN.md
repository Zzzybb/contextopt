# PR 说明：v0.9 手动真实 provider 评测工作流

## 为什么做

确定性的 ACM/数学 artifact 能证明协议和成本记账，但不能被包装成模型能力结论。需要给
已经配置 provider key 的操作者一条可复现路径，在同一固定矩阵上运行真实的
OpenAI-compatible endpoint。

## 改动内容

- 新增仅手动触发的 `real-agent-eval` GitHub Actions 工作流。
- 工作流接收 model、endpoint、fixture、strategy、repetition 参数；要求
  `CONTEXTOPT_API_KEY` secret，且不会打印它。
- dispatch 输入通过 step environment variable 传给 shell，且工作流会拒绝少于 3 次
  repetition。
- 将 JSON ledger、Markdown 报告、自包含 HTML dashboard、manifest 和 checkpoint 一起上传
  为一次运行的 artifact。
- 增加中英文使用说明，并沿用评测器的小样本结论边界。

## 结论边界

该工作流是操作者控制的探索性 benchmark，不声称通用模型能力、统计充分性、provider
稳定性、延迟保证、exactly-once 计费或生产安全。比较不同运行时必须固定 model、prompt、
fixture、工具、限制和 repetition。
