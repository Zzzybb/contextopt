# PR note: v1.0 cross-platform CI type-check fix

## Failure observed

CI run #67 failed in the `Lint and format check` step for Python 3.11, 3.12, and 3.13.
Ruff passed; mypy stopped the job on Windows-only `subprocess.CREATE_NEW_PROCESS_GROUP` and
`ctypes.WinDLL` attributes, plus POSIX-only process-group symbols whose availability differs
between the Windows and Linux type stubs.

## Fix

- Resolve platform-specific constants and functions through `getattr` with safe fallbacks.
- Keep the Windows Job Object path available at runtime while allowing the module to type-check
  on Linux runners and the local Windows interpreter.
- Fall back to terminating the direct process if a POSIX process-group primitive is unavailable.

## Validation

```text
python scripts/ci_checks.py
python -m unittest discover -s tests -p "test_*.py"
```

Local result: Ruff and mypy pass; all 219 tests pass with one existing Windows symlink-privilege
skip. No behavior change is intended on platforms that provide the native process-group APIs.
