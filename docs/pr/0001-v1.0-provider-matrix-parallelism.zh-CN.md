# PR 说明：v1.0 provider 矩阵有界并发

## 改动内容

- 将 `real-agent-model-matrix.yml` 的模型 cell fan-out 限制为最多两个并发 provider job。
- 保留 repository/ref concurrency group，因此不同 workflow run 会等待，同一 run 也会限制
  provider 压力。
- 用 workflow contract 测试锁定上限，并补充双语运行边界说明。

## 为什么做

多模型评测本身就是一个有界编排问题。一次启动所有模型可能触发 rate limit，让 provider 过载
掩盖单个 cell 的失败，还会产生不可控的费用峰值。小的明确上限仍保留并行性，同时让实验可审计、
可重复。

## 验证

~~~text
python -m unittest tests.test_workflow_contract -v
python scripts/ci_checks.py
~~~

## 结论边界

`max-parallel: 2` 只是 GitHub Actions 调度上限，不是 provider 吞吐保证；它不能证明延迟、稳定性、
取消能力或模型质量。
