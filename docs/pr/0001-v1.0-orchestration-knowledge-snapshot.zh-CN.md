# PR 说明：v1.0 多智能体编排知识快照

多智能体编排现在可以在 planner 第一次请求前，从完整的 `--root-files` JSON 快照刷新 durable
源码投影：

- `orchestrate --auto-index-knowledge` 必须显式提供 memory store 和 scope；
- `--knowledge-index-report` 与 `--knowledge-index-markdown` 输出创建/复用/失效分块数量和
  snapshot fingerprint；
- root-file 分块带独立的 `knowledge-snapshot-v1` tag，因此同一 scope 内的快照刷新不会使文件
  系统 workspace 索引分块失效；
- source 分块是 evidence 而不是 learned experience，因此编排结束时的
  `--memory-feedback` 不会更新它们的 retrieval signal；
- 该 flag 只支持新建编排；pending `resume` request 保留原本记录的 durable candidate 快照。

provider-free 测试覆盖重复索引、source isolation、快照失效、CLI 集成和 report 往返解析。

```text
python -m unittest tests.test_knowledge tests.test_orchestrator -v
python scripts/ci_checks.py
```
