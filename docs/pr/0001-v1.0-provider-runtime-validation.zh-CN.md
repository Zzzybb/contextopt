# v1.0 provider 运行时参数校验

## 改了什么

OpenAI-compatible adapter 现在会在创建传输前拒绝格式错误的运行参数：空或非字符串的身份字段、非有限数或
非正 timeout、布尔值或负 retry 次数，以及非有限数或负 temperature 都会以明确的 `ValueError` fail closed。

## 为什么改

Adapter 是把操作者配置转成 provider 请求的边界。让 `NaN`、无穷大、布尔值或空身份穿过边界，会产生
provider-specific 失败、不稳定 manifest 或误导性的重试行为。提前校验可以让请求 ledger 和 model-matrix
协议 fingerprint 保持有意义。

## 如何验证

- `python -m unittest tests.test_runtime_model -v`
- `python scripts/ci_checks.py`
- `python -m unittest discover -s tests -v`

## Claim boundary

这是本地配置校验，不代表 provider 可用性、价格、远端取消、模型能力或生产安全。
