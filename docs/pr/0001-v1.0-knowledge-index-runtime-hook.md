# PR note: v1.0 knowledge-index runtime hook

The workspace index is now available directly from the single-agent entry point:

- `run --auto-index-knowledge` refreshes the bounded source projection before the first model
  request;
- the flag requires an explicit semantic-memory store and scope, preventing an index that the
  context policy cannot retrieve;
- optional JSON/Markdown report paths expose the index accounting without adding noise to the run
  result stream;
- `resume` does not silently mutate the durable store before a pending request, preserving its
  explicit recovery configuration boundary.

The new CLI path is covered by a local round-trip test. It still uses lexical, source-aware
memory and does not claim embedding quality or model use of every retrieved chunk.

```text
python -m unittest tests.test_knowledge -v
python scripts/ci_checks.py
```
