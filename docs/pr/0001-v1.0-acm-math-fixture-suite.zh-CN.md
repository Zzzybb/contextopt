# PR #1 — v1.0 ACM/数学 fixture 任务集扩展

## 改动

- 将可执行代码 Agent 矩阵从两个完整 root snapshot 扩展到四个：`two-sum`、
  `merge-intervals`、`extended-gcd`、`modular-inverse`。
- 为区间排序/重叠合并、输入不可变性、负数模逆和非互质模数增加 visible 与独立 hidden
  grader。
- 保持 `single_pass`、`best_of_n`、planner/solver/reviewer `orchestrated` 三种控制策略、
  候选预算、hidden gate、checkpoint schema 和配对统计不变；CLI 的 `--fixtures all` 改为从
  fixture registry 解析，不再硬编码两个任务。
- 更新英文和中文版 README/runtime/evaluation 说明，让真实 provider 工作流在获得授权后有
  更宽的 ACM/数学任务面。

## 验证

```text
ruff check src/contextopt/evaluation/agent_search.py src/contextopt/cli.py tests/test_agent_search_eval.py
python -m unittest tests.test_agent_search_eval.AgentEvaluationFixtureTests
python -m unittest discover -s tests -v
```

脚本化的 all-fixture 矩阵在一次 repetition 下产生 12 个 cell；两个较强策略在四个 fixture
上都通过 visible 和独立 hidden grader，弱 single-pass control 仍作为失败数据点保留。

## 边界

新增任务提升了覆盖面和对抗性，但 scripted response 仍只是协议/控制基线，不能证明真实模型
代码能力、泛化、provider 稳定性或统计显著性。真实模型证据仍需固定 provider/model/prompt/
budget，并在获得授权后至少运行三次 repetition。
