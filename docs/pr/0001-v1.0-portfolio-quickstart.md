# PR note: v1.0 portfolio quickstart

## What changed

- Add a short English and Chinese README entry point for installing the package and running the
  provider-free model-matrix demo.
- Point the reader directly to the generated self-contained HTML dashboard and the authorized
  real-provider workflow.

## Why

The repository is intentionally deep, but a reviewer should be able to see a working ACM/math
agent-evaluation artifact in under a minute. The quickstart makes the learning/portfolio path
obvious without weakening the distinction between deterministic controls and real-model evidence.

## Validation

```text
python scripts/run_model_matrix_demo.py
python scripts/ci_checks.py
```

## Claim boundary

The quickstart runs only the provider-free `ScriptedModel` control replicas. The generated HTML
proves the local evaluator and accounting path, not coding quality or model generalization.
