# PR 变更说明约定（中文版）

从本 PR 开始，每个 Pull Request 都必须包含一份 Markdown 变更说明。说明文件
放在本目录，使用递增编号，例如：

- 0001-contextopt-evolution.md
- 0002-multi-agent-orchestration.md

每份说明至少包含：

1. 改了什么：模块、接口、CLI 和数据结构；
2. 为什么改：它解决了哪个 Agent 运行时问题；
3. 如何验证：测试命令、质量门禁和可复现示例；
4. 指标含义：哪些是工程/conformance 指标，哪些不能被解释成模型能力；
5. 已知边界：安全、恢复、真实模型和隐藏测试方面没有做什么。

历史 PR 不重写原说明；如需补充，新增带版本或语言后缀的说明文件。英文说明和
中文说明应保持相同的事实、命令和 claim boundary。
