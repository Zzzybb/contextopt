# v0.8 bounded MCTS scheduler addendum

## Scope

This follow-up adds a second, auditable branch-selection policy while keeping `beam` as the
reproducible baseline:

- `BranchSearchConfig.search_policy` accepts `beam` or `mcts`, and
  `exploration_constant` is persisted with the report;
- `mcts` traverses the already generated parent-linked `CandidatePatch` tree with a
  deterministic UCT score; unobserved children are explored first, then observed visible-test
  quality is propagated through the selected parent path;
- every selection emits `candidate.selected` with parent visits, candidate visits, a UCT score
  (or an explicit first-visit null), and candidate value; rollout and terminal events stay in
  the existing hash chain;
- workspace fingerprint deduplication, candidate/depth/test budgets, `stop_on_pass`, and the
  trusted executable oracle boundary are unchanged;
- `branch-search`, `search-session`, `orchestrate`, and `agent-eval` expose
  `--search-policy mcts`; the HTML/Markdown/console reports expose the selected policy.

## Why

The earlier adaptive scheduler selected the next parallel batch from parent quality, but the
pure branch core still used only beam ordering. MCTS makes the tree policy explicit and gives an
interviewer a concrete long-running search story: observations become bounded state, rewards are
propagated to ancestors, and each decision can be replayed from the ledger. It intentionally
does not let the model invent a reward or execute an untrusted merge.

## Evidence

The deterministic test constructs three root hypotheses with different visible-test quality and
asserts that, after root exploration, MCTS selects the child of the highest-quality parent. It
also verifies deterministic report round-tripping, selection-event fields, CLI wiring, and the
existing full gates:

```text
python -m unittest tests.test_branch_search -v
python -m unittest tests.test_search_session tests.test_orchestrator -q
python -m contextopt agent-eval --fixtures all --repetitions 1 --search-policy mcts
python -m ruff check src tests
python -m mypy src/contextopt
python -m unittest discover -s tests -q
python scripts/ci_checks.py
```

## Claim boundary

This is bounded UCT over a fixed candidate graph, not model-on-demand PatchTree expansion,
speculative model calls, merge-aware multi-agent search, or a security sandbox. The reward is
only the visible-test `quality_score`; hidden graders are never used to schedule candidates.
The scripted fixture proves scheduler accounting and replayability, not model coding ability,
generalization, provider reliability, or production safety.
