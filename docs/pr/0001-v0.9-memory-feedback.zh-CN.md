# v0.9 后续 — 幂等的语义记忆反馈

## 摘要

本次不引入未经审计的 embedding 服务，而是把检索闭环补齐：Agent 使用一条记忆后可以
标记 helpful / not_helpful，后续检索会得到一个透明且有界的排序调整。

## 改动

- 新增 append-only 的 `memory.feedback` 事件和 `MemoryFeedbackResult` 聚合结果；
- 新增仅在写权限打开时暴露的 `memory_feedback` 工具，支持 `helpful` / `not_helpful`；
- 使用 durable tool-call id 作为幂等键：重试返回同一 revision、不重复计票；同一 id 搭配
  不同 payload 会被拒绝；
- 检索结果暴露 `feedback_signal`，并最多施加 `0.05` 的有界分数调整；记忆正文、provenance、
  scope 和失效语义不变；
- 扩展无 provider 检索产物，并在中英文说明中加入 feedback probe。

## 结论边界

这是一层可审计启发式，不是学习型置信度校准、语义理解，也不能证明模型给出的 label 正确。
固定 probe 只证明事件重放、重试幂等和有界排序变化。未来的学习型 retriever 仍需 held-out
tasks 和显式消融实验。
