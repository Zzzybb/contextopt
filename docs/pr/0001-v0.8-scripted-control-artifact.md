# v0.8 PR addendum: scripted three-repetition control artifact

## What changed

- Checked in a deterministic three-repetition `agent-eval` artifact for both bundled fixtures:
  `two-sum` and `extended-gcd`.
- The matrix covers `single_pass`, `best_of_n`, and `orchestrated`, with visible tests,
  independent hidden graders, paired deltas, Wilson intervals, token/model-call accounting, a
  checkpoint, and a reproducibility manifest.
- Added a short experiment README and linked the artifact from the English and Chinese project
  entry points.

## Verification

Regenerate the exact artifact from the repository root with:

```text
python -m contextopt agent-eval --fixtures all --repetitions 3 \
  --output experiments/v0.8-scripted-3-reps/report.json \
  --markdown experiments/v0.8-scripted-3-reps/report.md \
  --html experiments/v0.8-scripted-3-reps/report.html \
  --checkpoint experiments/v0.8-scripted-3-reps/checkpoint.json \
  --manifest experiments/v0.8-scripted-3-reps/manifest.json
```

The checked-in run contains 18 evaluations: two fixtures × three strategies × three
repetitions. The generated report records the visible/hidden pass rates, paired comparisons,
confidence intervals, budgets, and checkpoint/manifest metadata.

## Boundary

This is a protocol and accounting control baseline, not evidence about real-model coding quality.
The responses come from the deterministic `ScriptedModel`; provider reliability, generalization,
latency, and production safety are not measured. Before making model-quality claims, replace the
scripted factory with an explicitly versioned provider and rerun the same matrix with an API key.
