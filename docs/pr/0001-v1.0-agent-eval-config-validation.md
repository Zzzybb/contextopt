# v1.0 agent-eval configuration validation

## What changed

`AgentEvalConfig.exploration_constant` now accepts only finite positive numeric values,
both when constructed directly and when loaded from a serialized configuration. Booleans,
`NaN`, infinity, and non-positive values fail closed before the evaluation scheduler starts.

## Why

The exploration constant controls MCTS branch selection. Letting a non-finite value through
can make UCT scores non-deterministic or silently disable the intended budgeted search policy.
Configuration and checkpoint boundaries should reject malformed numeric controls before any
model or test call is issued.

## Validation

- `python -m unittest tests.test_agent_search_eval -v`
- `python scripts/ci_checks.py`
- `python -m unittest discover -s tests -v`

## Claim boundary

This is configuration validation for the local evaluation scheduler. It does not claim MCTS
quality, model generalization, provider reliability, sandbox security, or statistical power.
