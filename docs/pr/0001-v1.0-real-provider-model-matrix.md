# PR note: v1.0 manual real-provider model matrix

## What changed

- Add `.github/workflows/real-agent-model-matrix.yml`, a manually triggered matrix workflow for
  running the same `agent-eval` protocol against at least two labelled models.
- Validate the JSON model list, safe artifact labels, duplicate labels, and the minimum
  three-repetition paired budget before creating the job matrix.
- Record one manifest, checkpoint, HTML/Markdown report, and provider transcript cassette per
  model, then run `agent-eval-compare` in a final job and upload the machine-readable and dashboard
  comparison artifact.
- Document the workflow in English and Chinese provider-evaluation guides and this bilingual PR
  note.

## Why

The previous manual workflow produced one provider bundle at a time, leaving operators to create
the second bundle and invoke the protocol-checked analyzer by hand. This workflow makes the
cross-model experiment itself reproducible: endpoint, role overrides, fixtures, strategies,
budgets, sandbox, revision, and repetition count are shared by every cell, while model identity
remains the intended independent variable.

## Validation

```text
python scripts/ci_checks.py
python -m unittest discover -s tests -p 'test_*.py'
```

The suite includes a workflow-contract test for the manual fan-out, secret boundary, transcript
recording, and final artifact aggregation. The workflow itself requires an explicitly configured
`CONTEXTOPT_API_KEY` secret. It is not run by pull requests and does not contact a provider during
ordinary CI.

## Claim boundary

This change adds orchestration and artifact plumbing, not model-quality evidence. The final
`agent-eval-compare` report remains a fixed, small-sample descriptive comparison; it rejects
protocol drift but does not establish generalization, statistical power, provider reliability,
latency guarantees, remote cancellation, or production security. A provider result exists only
after an operator runs the workflow with an authorized endpoint and inspects the uploaded evidence.
