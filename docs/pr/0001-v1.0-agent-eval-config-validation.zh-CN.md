# v1.0 agent-eval 配置校验

## 改了什么

`AgentEvalConfig.exploration_constant` 现在只接受有限正数；无论是直接构造，还是从序列化配置加载，
布尔值、`NaN`、无穷大和非正数都会在评测调度器启动前 fail closed。

## 为什么改

这个 exploration constant 控制 MCTS 分支选择。非法有限性数值可能让 UCT 分数不可复现，或静默破坏原本
有界的搜索策略。配置和 checkpoint 边界应该在发出任何模型/测试调用前拒绝畸形数值控制。

## 如何验证

- `python -m unittest tests.test_agent_search_eval -v`
- `python scripts/ci_checks.py`
- `python -m unittest discover -s tests -v`

## Claim boundary

这是本地评测调度器的配置校验，不声称 MCTS 质量、模型泛化、provider 稳定性、sandbox 安全性或统计功效。
