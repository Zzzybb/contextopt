# PR 说明：v1.0 原子 checkpoint 中断边界

## 改动内容

- 增加 fault-injection 测试，在 `write_projection_checkpoint` 的原子 `os.replace` 边界模拟
  中断。
- 验证旧 checkpoint 仍能按原 event prefix 读取，并且失败替换后的临时文件会被清理。
- 用中英文说明记录证据和结论边界。

## 为什么做

长程 Agent 必须能承受进程或机器在持久化恢复状态时停止。普通 round-trip 测试只能证明序列化，
不能说明最终 rename 失败时的行为。这个测试锁定原子写入契约，但不冒充硬件持久性保证。

## 验证

~~~text
python -m unittest tests.test_runtime_recovery -v
python scripts/ci_checks.py
~~~

## 结论边界

这是本地模拟的替换失败。它证明在该注入故障下最后一份完整 cache 会保留、临时文件会清理；
不代表文件系统持久性、掉电恢复、分布式存储或 exactly-once 外部副作用保证。
