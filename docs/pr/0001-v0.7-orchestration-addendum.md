# PR #1 addendum: planner / solver / reviewer orchestration

This addendum records the v0.7 role layer added after the original PR #1 retrospective.

## What changed

- Added strict planner and reviewer JSON protocols and a solver request that reuses the
  complete workspace-snapshot proposal parser.
- Added a sequential OrchestrationRunner with planner, solver, disposable visible-test
  evaluation, and reviewer phases.
- Added shared model/token/candidate/test budgets, per-role model fingerprints, cross-round
  feedback, cached observations, atomic checkpoints, role-call hashes, and Markdown output.
- Added an oracle gate: accepted requires reviewer decision accept plus a visible-test-passing
  candidate. Reviewer confidence cannot override the executable result.
- Added the orchestrate CLI command, deterministic role conformance tests, and the Chinese
  README and PR documentation.

## Validation

~~~text
python -m unittest tests.test_orchestrator -v
python -m ruff check src tests
python -m ruff format --check src tests
python -m mypy src/contextopt
~~~

These checks establish protocol, budget, persistence, and safety behavior for scripted
models. They do not establish real-model coding quality, hidden-test success, or a
multi-agent advantage. Parallel isolated workspaces, adaptive scheduling, and a controlled
real-model benchmark remain future milestones.
