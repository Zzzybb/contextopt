# v0.9 后续 — 可审计的跨运行语义记忆

## 摘要

本次后续改动为 ForgeAgent 增加显式语义记忆边界。已有的 `versioned-v1` 观察记忆仍然是
当前 workspace transcript 的事实来源；新 store 是跨运行的提示型 notebook，Agent 必须
显式调用工具查询，不能把它当成当前文件状态。

## 改动

- 新增 `SemanticMemoryStore`：schema-1 append-only JSONL 事件日志，复用 runtime trace 的
  hash-chain 和跨进程 lease；
- 支持 `fact`、`decision`、`procedure`、`failure` 四类记忆，记录 scope、tags、confidence、
  source run/reference、内容 digest，以及显式 invalidation/supersession 状态；
- 新增不依赖 embedding 的确定性 lexical retrieval，返回匹配词证据，支持 `global` scope
  继承、稳定排序和 revision/fingerprint；
- `WorkspaceTools` 暴露 `memory_search`；只有打开 `--allow-write` 时才暴露幂等的
  `memory_save` 和显式的 `memory_invalidate`，save 可以 supersede 旧条目，三者都按
  safe replay 处理；
- `contextopt run/resume --memory-store PATH` 接入语义记忆，并把 store 身份纳入 tool
  configuration fingerprint；文档明确记忆只是提示，不是 mutable workspace 的证明；
- 增加 append-only replay、去重、scope/tag、supersession、invalidation、工具输出和写权限
  测试。

## 结论边界

当前实现没有 embedding 依赖、自动 summarizer 或学习型 confidence calibration。lexical
检索证明的是持久化记忆 plumbing 和 provenance 可审计，不证明记忆能提升模型编码成功率。
store 使用 lease 拒绝并发 writer；`memory_save` 的 identity 由内容生成，因此中断后可以安全
重试。
