# PR note: v1.0 orchestration knowledge snapshot

Multi-agent orchestration can now refresh the durable source projection from its complete
`--root-files` JSON snapshot before the planner request:

- `orchestrate --auto-index-knowledge` requires an explicit memory store and scope;
- `--knowledge-index-report` and `--knowledge-index-markdown` expose created/reused/invalidated
  chunk counts and a snapshot fingerprint;
- root-file chunks carry a dedicated `knowledge-snapshot-v1` tag, so snapshot refreshes do not
  invalidate filesystem workspace-index chunks in the same scope;
- source chunks are evidence rather than learned experience, so orchestration terminal
  `--memory-feedback` does not update their retrieval signal;
- the flag is restricted to new orchestrations; pending `resume` requests keep their recorded
  durable-candidate snapshot.

The provider-free tests cover repeatable indexing, source isolation, snapshot invalidation, CLI
integration, and report round-tripping.

```text
python -m unittest tests.test_knowledge tests.test_orchestrator -v
python scripts/ci_checks.py
```
