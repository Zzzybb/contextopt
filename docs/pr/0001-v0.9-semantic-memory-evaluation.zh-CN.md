# v0.9 后续 — 语义记忆检索评测

## 摘要

本次后续把 durable semantic-memory plumbing 变成可重复的评测产物，同时明确不把固定的
lexical fixture 包装成模型智能。

## 改动

- 新增 `contextopt memory-eval`：无 provider 的固定 fixture，包含 global/project scope、
  tags、正向查询、负查询和一条显式失效的旧记忆；
- JSON、Markdown、自包含 HTML 报告记录 hit@1、hit@k、MRR、负查询通过率、scope 隔离率、
  失效条目排除率、重复检索确定性、命中词、分数和原始 memory id；
- 增加单元测试和 CLI 产物测试，并把重新生成的报告放在
  `experiments/v0.9-semantic-memory`；
- 在两份 README、runtime/evaluation 指南中补充指标定义和 claim boundary。

## 结论边界

评测不调用模型，使用 runtime store 相同的确定性 lexical scorer。固定 fixture 的满分只证明
持久化、过滤、失效和可复现排序正确，不证明 embedding 质量、语义理解、Agent 是否会选择
有用记忆或代码任务成功率。未来的学习型 retriever 必须使用 held-out tasks，并和这个 baseline
做显式消融。
