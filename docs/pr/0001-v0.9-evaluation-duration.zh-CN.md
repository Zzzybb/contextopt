# PR 说明：v0.9 Agent 评测本地耗时记账

## 为什么做

现有评测已经记录模型调用、候选和 oracle 测试成本，但没有为每个矩阵单元保留运行时间。
这样可以比较成功率和成本，却无法讨论长程代码 Agent 很重要的本地时间取舍。

## 改动内容

- 为每个 fixture/strategy/repetition 单元记录单调时钟测得的本地墙钟 `duration_ms`；
- 按策略汇总 `mean_duration_ms`，并在配对比较中增加耗时均值和观测总体标准差差值；
- 在 console、Markdown、HTML 摘要和 run ledger 中展示耗时；
- 保持 checkpoint/report 向后兼容：没有耗时字段的旧报告显式默认成 0；恢复运行时，
  只对确定性的字段做一致性比较，不把重新执行的时间当成相等；
- 同步更新中英文 README/评测口径，并补充本中英文 PR 说明。

## 验证命令

git diff --check

## 结论边界

`duration_ms` 是评测器围绕一个矩阵单元测得的本地墙钟时间。真实 provider 模式下它会
包含 adapter 等待的网络/provider 时间，但不是 provider 延迟 SLA、吞吐 benchmark，
也不是模型能力证据。固定 ScriptedModel 矩阵仍然只是协议和控制策略一致性 artifact。
