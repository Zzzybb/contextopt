# v1.0 runtime limit 参数校验

## 改了什么

`RunLimits` 现在会在直接构造和从 checkpoint 加载时，校验 wall/command timeout 必须是有限正数，turn、
tool-call、output-token 和 output-byte 限制必须是严格正整数；可选 total-token 限制也会拒绝布尔值和非正数。

## 为什么改

长程 Agent 依赖 limits 作为安全与成本边界。Python 的比较语义可能让 `NaN`、无穷大、浮点数或布尔值穿过
部分直接构造路径，造成无界或不可复现的运行。现在 limits 会在 runner 启动前 fail closed。

## 如何验证

- `python -m unittest tests.test_runtime -v`
- `python scripts/ci_checks.py`
- `python -m unittest discover -s tests -v`

## Claim boundary

这是本地配置和 checkpoint 数据校验，不保证调度公平性、provider 计费、OS 隔离或外部副作用 exactly-once。
