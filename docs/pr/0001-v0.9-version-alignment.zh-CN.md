# PR 说明：v0.9 包版本对齐

## 为什么做

仓库已经完成 v0.9 长程恢复和 Agent 评测里程碑，但包元数据和 `contextopt --version`
仍然显示 `0.8.0a1`。这会让实验产物、问题报告和面试演示无法明确对应实际协议版本。

## 改动内容

- 将打包元数据和运行时 `__version__` 统一为 `0.9.0a1`；
- 增加回归测试，证明导入的版本号与已安装 distribution metadata 一致；
- 同时补充中英文 PR 变更说明。

## 验证命令

~~~text
python -m unittest tests.test_package_metadata -v
python -m contextopt --version
python scripts/ci_checks.py
~~~

## 结论边界

这是发布身份记账，不代表新增模型能力、provider 兼容性或统计严谨的真实模型
benchmark。v0.9 仅表示仓库文档中已经实现的本地恢复/评测里程碑。
