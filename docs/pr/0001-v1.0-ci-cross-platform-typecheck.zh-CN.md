# PR 说明：v1.0 跨平台 CI 类型检查修复

## 失败现象

CI run #67 在 Python 3.11、3.12、3.13 的 `Lint and format check` 阶段全部失败。Ruff 已通过，
mypy 报错集中在 Windows 专用的 `subprocess.CREATE_NEW_PROCESS_GROUP`、`ctypes.WinDLL`，以及
POSIX 进程组符号：不同平台的类型存根对这些属性暴露不一致。

## 修复内容

- 对平台相关常量和函数统一使用 `getattr`，并提供安全 fallback；
- 保留 Windows Job Object 的运行时路径，同时让同一模块能在 Linux runner 和本地 Windows
  解释器下通过类型检查；
- POSIX 进程组原语不可用时，退化为终止直接子进程。

## 验证

```text
python scripts/ci_checks.py
python -m unittest discover -s tests -p "test_*.py"
```

本地结果：Ruff、mypy 通过；219 个测试全部通过，另有 1 个既有的 Windows symlink 权限测试跳过。
在提供原生进程组 API 的平台上，预期行为没有变化。
